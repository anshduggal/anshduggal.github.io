Intelligent Upper Limb Rehabilitation Exoskeleton

Oct 2024 – May 2025 | Final-Year BEng Project, University of Leeds

For my final-year project, I designed and delivered a low-cost, lightweight powered exoskeleton focused on elbow and wrist rehabilitation for stroke patients and individuals with upper-limb motor impairments.

  • Conducted full mechanical design in SolidWorks: topology optimisation + strategic material selection (PLA, carbon fibre inserts, aluminium linkages) → achieved 20% overall weight reduction while maintaining structural integrity under 5 kg load
  • Developed closed-loop position and force control algorithms in embedded C running on STM32, with real-time sensor fusion (IMUs + flex sensors)
  • Built a remote therapy interface (Python + serial communication) allowing clinicians to run automated movement assessments, log progress, and adjust therapy parameters remotely
  • 3D-printed functional prototype with integrated actuation, tested joint range of motion and control accuracy
  • End-to-end ownership: concept → CAD → firmware → prototyping → testing → documentation

7 ft Wingspan Airbus A350 RC Airliner

Mar 2020 – Feb 2021 | Personal Passion Project

Designed, constructed, and successfully flew a 7 ft (2.1 m) wingspan EDF-powered scale model of the Airbus A350-900 — one of the largest and most detailed RC airliners built by a high-school student in India at the time.

  • Full aerodynamic design and airframe construction using Depron foam reinforced with carbon fibre spars and fibreglass → 20% weight reduction compared to traditional balsa builds
  • Custom flight controller based on ATmega328P (Arduino architecture) with full integration of ailerons, flaps, elevators, rudder, retracts, and dual 70 mm EDF units
  • Applied control surface mixing, expo tuning, and failsafe logic for stable maiden flight
  • Demonstrated advanced skills in prototyping, composite materials, systems integration, and applied aerodynamics from initial sketches to multiple successful flights

Snake Game on ST Nucleo-L476RG

Mar – May 2024 | Embedded Systems Course, University of Leeds

Implemented the classic Snake game from scratch in C++ on bare-metal STM32L476RG — a complete real-time embedded application with zero external libraries.

  • Integrated multiple peripherals simultaneously: 4-direction joystick for input, 16×2 LCD for graphics rendering, and buzzer for sound effects
  • Designed clean state-machine architecture with interrupt-driven controls and debouncing
  • Full firmware development cycle using Mbed/Keil Studio: writing drivers, memory management, timing optimisation, and thorough debugging
  • Delivered a responsive, polished game running at 60+ FPS on constrained hardware

FPGA-Based Electronic Dice Game

Mar – May 2024 | Digital Systems Course, University of Leeds

Designed and implemented a fully functional 1–6 electronic dice roller entirely in Verilog HDL on an Intel FPGA development board.

  • Created pseudo-random number generation using linear-feedback shift register (LFSR)
  • Built complete sequential logic: button debouncing, seven-segment display driver, roll animation, and hold state
  • Wrote modular testbenches in ModelSim to verify functionality at gate level before synthesis
  • Successfully synthesised, performed timing analysis in Quartus, and deployed on real hardware

Microcontroller-Controlled Washing Machine Prototype

Mar – May 2023 | Embedded Systems Course

Designed and built a complete washing machine control system using the STM32L476RG microcontroller — simulating a real domestic appliance control panel.

  • Implemented full feature set: wash cycle selection, water level sensing, temperature control, motor direction/speed control, and door lock safety interlock
  • Real-time serial monitoring interface for diagnostics and parameter tuning
  • Developed robust state machine handling timing, sensor inputs, and fault detection
  • Demonstrated strong embedded systems skills: peripheral configuration, interrupt handling, and hardware-software co-design
