Intelligent Upper Limb Rehabilitation Exoskeleton

Oct 2024 – May 2025 | Final-Year BEng Project, University of Leeds

Designed and built from scratch a powered, lightweight upper-limb exoskeleton for rehabilitation of stroke patients and motor-impaired individuals. Focused on elbow flexion/extension and wrist pronation/supination.

  • Full mechanical design in SolidWorks: topology optimisation, FEA, material selection (PLA + carbon fibre inserts + aluminium) → achieved 20% weight reduction vs traditional designs while supporting 5+ kg load
  • Implemented closed-loop position & force control in embedded C on STM32H7 with real-time sensor fusion from IMUs, flex sensors, and load cells
  • Developed remote clinician dashboard in Python (PyQt + serial) for therapy prescription, real-time monitoring, and data logging
  • Integrated brushless DC actuation with custom driver board, back-drivable joints, and emergency stop
  • 3D-printed full working prototype, performed human trials for ROM and control accuracy
  • End-to-end ownership: requirements → CAD → firmware → electronics → assembly → testing → documentation

One of the most advanced individual projects in the 2025 cohort.

7 ft Wingspan Airbus A350-900 RC Airliner

Mar 2020 – Feb 2021 | Personal Passion Project

One of the largest and most detailed RC airliners ever built by a high-school student in India at the time. Full scale model of the Airbus A350-900 with working flaps, slats, landing gear, lights, and dual 70mm EDFs.

  • Designed entire airframe from scratch using Depron foam, carbon fibre spars, and fibreglass reinforcement → 20% lighter than equivalent balsa builds
  • Built custom flight controller on ATmega328P with full sensor suite and control surface mixing
  • Implemented expo, dual rates, failsafes, and retract logic for safe flight
  • Successfully completed multiple flights including touch-and-go and low passes
  • Featured in Indian RC forums and inspired many younger builders

Snake Game on STM32 Nucleo-L476RG

Mar – May 2024 | Embedded Systems Course

Full from-scratch implementation of the classic Snake game on bare-metal STM32 — no libraries, no OS, pure C++ and direct hardware control.

  • Simultaneous control of joystick (ADC + interrupts), 16×2 LCD (HD44780 driver), and buzzer (PWM tones)
  • Custom game engine with collision detection, scoring, increasing speed, and game states
  • Interrupt-driven input with debouncing and real-time rendering at 60+ FPS
  • Clean modular code with separate drivers, game logic, and display management
  • One of the most polished projects in the class

FPGA-Based Electronic Dice Game

Mar – May 2024 | Digital Systems Course

Fully functional electronic dice (1–6) built entirely in Verilog HDL on Intel Cyclone IV FPGA.

  • Pseudo-random number generation using Linear Feedback Shift Register (LFSR)
  • Button debouncing, roll animation with easing, seven-segment display driver
  • Hold state, reset logic, and smooth roll-to-stop transition
  • Full testbenches in ModelSim, timing analysis in Quartus, zero errors on hardware
  • Deployed and demoed live on real FPGA board

Microcontroller-Controlled Washing Machine Prototype

Mar – May 2023 | Embedded Systems Course

Complete simulation of a real domestic washing machine using STM32L476RG — full control panel with safety and diagnostics.

  • Full feature set: cycle selection, water level/temp sensing, motor control (direction + speed), door lock, imbalance detection
  • Real-time serial monitoring dashboard for diagnostics and parameter tuning
  • Robust state machine with timing, fault detection, and recovery
  • Hardware-software co-design: custom PCB design, sensor integration, interrupt handling
  • One of the top-performing projects in the year
